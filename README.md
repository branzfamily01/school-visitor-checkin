# 来校チェック

Excel / CSV 名簿を各端末のブラウザ内で読み込み、来校者の本人情報・抽選結果・受付済み状態を素早く照合する静的Webアプリです。来場可否を判定することが目的ではなく、抽選受付を前提に「目の前の方が誰か」を確認して来校記録を残すことを目的にしています。

## 主な機能

- カタカナ・ひらがな・漢字・受付IDから部分検索
- 当選 / 落選・学校名・学年・人数・補助情報の照合
- 1タップ受付、受付時刻、取消、二重受付表示
- 名簿外来校者の登録
- 端末内への自動保存、ブラウザを閉じた後の再開
- 来校記録CSV、名簿外CSV、バックアップJSON
- 複数受付PCの匿名同期（別Wi-Fi / テザリングでも可）
- 通信断中もローカル受付を継続し、復旧後に未同期分を送信
- PWA / オフライン基本画面・manual.htmlキャッシュ
- 別形式Excel向けの汎用列マッピング

## 8/22実データの自動プリセット

`2nd見学会当選８２２(1).xlsx` の `7kai` シートを自動認識します。

- A列: 受付ID
- B列: 当落フラグ（`t` / `ｔ` = 当選）
- C列: 回
- D列: 氏名
- E列: フリガナ
- F列: 学年
- H列: 学校名
- J列: 人数
- K列: 補助情報
- 有効名簿: 594件
- B列の当選フラグ: 280件

## 複数端末同期

各PCに同じ名簿を読み込み、⚙設定から端末名と同じ同期コードを設定します。同一LANは不要で、各PCがそれぞれインターネットへ接続できれば共有できます。

同期サーバーへ保存するのは次だけです。

- 名簿と同期コードから生成した匿名ID
- 受付 / 取消
- 受付時刻
- 受付端末名

氏名、フリガナ、学校名などの名簿内容は送信しません。クラウド表はブラウザの公開鍵から直接読み書きできない構成で、専用同期APIを経由します。

通信できない間も受付は各端末内へ保存され、復旧後に自動同期します。通信断中だけは他端末の最新状態が見えないため、二重受付に注意してください。

## 名簿外来校者

名簿外の氏名・フリガナ・学校名・メモは入力した端末内だけに保存します。同期時は匿名IDのみ共有するため、全端末で名簿外人数は共有できますが、他端末が入力した氏名一覧は自動集約しません。必要なら各端末の「名簿外CSV」を保存してください。

## 個人情報

名簿Excelはこのリポジトリ・ZIPに含めません。GitHub Pagesへ公開する際も実名名簿をリポジトリへアップロードしないでください。共有PCでは受付終了後に、アプリの「この端末から名簿＋受付データを完全削除」を実行してください。
