このアプリは何をするもの？

受付で来校者の名前を入力し、Excel名簿の本人情報・当選/落選・受付済みかをすぐ確認するアプリです。抽選結果にかかわらず、来た方は本人確認後に受付します。

まずこれだけ

受付担当者の基本3ステップ

名前をカタカナで数文字入力候補がすぐ出ます。漢字や受付IDでも検索できます。
本人情報と「当選 / 落選」を確認同姓同名なら、受付ID・学校名・学年なども見ます。
「この方で受付」を押す「受付済」と時刻が残ります。次の方の検索へ進みます。
名簿にいない方も入場できます。
検索で見つからなければ 「＋ 名簿外として受付」 を押します。

受付を始める

初回

「Excel / CSV を選ぶ」を押す受付で使う名簿ファイルを選びます。
自動認識を確認今回の8/22名簿は「7kai」シートを自動認識し、B列の t / ｔ 280件を当選として扱います。
受付を開始検索欄が出れば準備完了です。

一度閉じた後

同じPC・同じブラウザなら、起動時に「前回の受付があります」が出ます。「前回の受付を続ける」を押せば、Excelを選び直さず続きから再開できます。

シークレットモードやブラウザのサイトデータ削除を使うと、端末内の保存データが消えることがあります。受付当日は通常モードを使ってください。

この方で受付

カタカナは途中まででも検索できます。空白、全角/半角、ひらがな/カタカナの違いはできるだけ吸収します。

検索候補には氏名・フリガナ・受付ID・当選/落選・学校名・学年・人数・補助情報が表示されます。本人が特定できたら 「この方で受付」 を押します。

当選者も落選者も受付操作は同じです。このアプリの目的は「入場を許可するか」ではなく、目の前の方が誰かを確認して来校記録を残すことです。

すでに受付済みの場合

候補に「受付済 10:31」と出て、通常の受付ボタンは出ません。複数端末同期中なら「受付A」など、どの端末で受付したかも表示されます。

パソコン3台などで同時に使う

3台が同じWi-Fiにつながっている必要はありません。PCごとに学校Wi-Fi、スマホのテザリングなど別のネット回線でも、インターネットへ接続できれば共有できます。

最初の1台

⚙ 設定 →「複数受付端末を同期」端末名を「受付A」などにします。
「新しく作る」を押す同期コードが表示されます。
「同期を開始」を押す緑の「● 同期中」になれば接続完了です。

2台目・3台目

同じ名簿を読み込み、端末名を「受付B」「受付C」に変え、1台目と同じ同期コードを入力して 「同期を開始」 を押します。

同期コードは当日の受付チームだけで共有してください。 同じ名簿と同じコードを使った端末が、同じ受付グループになります。

通信が切れたら

画面に「⚠ 他の受付端末とは現在同期されていません」と出ます。

受付は止めないこのPCにはそのまま記録されます。
「未同期 ○件」を確認他のPCにはまだ届いていない件数です。
通信が戻れば自動同期必要なら 「今すぐ同期」 を押します。
通信断中だけは、別PCで同じ方を受付してもその場では分かりません。完全に圏外の場合は、一時的に「あ〜さ行」「た〜は行」「ま〜わ行」のように受付列を分けると二重受付を減らせます。

名簿にない方が来たとき

検索しても候補が出なければ、「＋ 名簿外として受付」を押します。

フリガナだけ必須です。氏名・学校名・メモは必要に応じて入力します。

複数端末同期中、名簿外の氏名そのものはクラウド共有しません。匿名IDだけ共有します。そのため、ほかのPCでは名簿外人数は共有できますが、そのPCで入力していない名簿外の氏名一覧までは表示されません。名簿外の氏名をまとめて残す必要がある場合は、各受付PCから「名簿外CSVを書き出す」を保存してください。

データについて

データどこに保存？端末間共有？
氏名・フリガナ・学校名などのExcel名簿このPCのブラウザ内しない
受付済み・時刻このPC内に自動保存同期ONなら匿名IDで共有
名簿外の氏名・学校名・メモ入力したPC内氏名等は共有しない
同期サーバー匿名ID・受付/取消・時刻・端末名同じ同期コードの受付間で共有

端末内保存には、ブラウザのIndexedDB / localStorageという仕組みを使います。簡単に言うと「このPCのこのブラウザの中に保存する」方式です。

バックアップ

⚙ 設定の 「バックアップJSON」 を押すと、この端末の受付状態をファイルとして保存できます。念のため休憩時・受付終了時にも保存しておくと安全です。

受付終了後

共有PCの場合は、CSVやバックアップを必要な場所へ保存した後、「この端末から名簿＋受付データを完全削除」で個人情報を消してください。

間違えたとき

違う人を受付してしまった

その人をもう一度検索し、「受付を取り消す」を押します。同期中なら取消もほかの端末へ共有されます。

名簿外を間違えて登録した

同じ名前を検索し、「登録を取り消す」を押します。

受付を全部やり直したい

⚙ 設定の 「この名簿の受付記録だけをリセット」を使います。元に戻せないため、必要なら先にバックアップしてください。

別のExcel・別イベントで使う

8/22ファイル以外でも使えます。自動認識されない場合は⚙設定で、次の列を指定します。

設定例

フリガナ列E列
学校名・学年・人数・補助情報必要な列を選択

列を決めたら 「この設定で受付を開始」を押します。

困ったとき

症状：Excelを読み込めない原因：古いブラウザ、壊れたExcel、未対応形式など。
対処：最新のChrome / Edge / Safariで開き、.xlsx またはCSVを使ってください。
症状：名前が見つからない原因：名簿の表記違い、フリガナ誤り、名簿外など。
対処：苗字だけ・受付ID・漢字でも検索し、それでもなければ名簿外受付を使います。
症状：別PCの受付が反映されない原因：同期OFF、同期コード違い、別名簿、通信断。
対処：「同期設定」で端末名とコードを確認し、緑の「● 同期中」になるか見ます。
症状：「● オフライン」になった原因：インターネットへ出られません。
対処：受付は続けて大丈夫です。Wi-Fiやテザリングを直すと自動同期します。
症状：画面を閉じてしまった原因：誤操作でも問題ありません。
対処：同じブラウザで開き直し、「前回の受付を続ける」を押します。

スマホ・iPhoneで使う方法

GitHub Pagesの公開URLをSafariで開けます。iPhoneなら共有ボタン → 「ホーム画面に追加」でアプリのように起動できます。

一度オンラインでアプリとこのマニュアルを開いておけば、PWAのキャッシュにより通信が不安定でも基本画面とマニュアルを開けます。Excel名簿は端末内に保存されたものを再開できます。

複数端末のリアルタイム共有だけはインターネット通信が必要です。オフラインでも受付記録そのものはこの端末に残ります。

用語集

同期受付Aで付けた「受付済み」を受付B/Cにも反映すること。
同期コード同じ受付イベントの端末をひとまとまりにする合言葉。全受付PCで同じものを使います。
未同期このPCには保存済みだが、まだほかのPCへ共有できていない受付記録。
匿名ID氏名をそのまま送らず、名簿と同期コードから作る識別用の文字列。
IndexedDB / localStorageWebブラウザが、この端末の中にデータを保存する仕組み。
PWAWebページをホーム画面からアプリのように使い、必要なファイルをオフライン用に保存できる仕組み。
