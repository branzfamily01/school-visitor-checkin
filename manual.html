目高祭受付版

このアプリは何をするもの？

目高祭の来校者を、名簿からすばやく探して「来た」と記録する受付アプリです。

在校生保護者・中学生と保護者・一般を分けて受付できます。混雑したら、その場で 「全分類」 に切り替えて全員を同じ検索欄から探せます。

最初にここだけ

まずこれだけ

「Excel / CSV を選ぶ」目高祭受付名簿.xlsx を選びます。最初の1回だけです。
日付と分類を選ぶ例：9/5 → ② 中学生・保護者。在校生保護者はさらに1〜3年を選べます。
名字を入力 → 本人確認 → 「この方で受付」一般・中学生は受付番号の全文または下5桁でも探せます。
ポイント： 受付した瞬間にこの端末へ自動保存されます。画面を閉じても、次回は 「前回の受付を続ける」 から再開できます。

画面の見方

9/5① 在校生保護者② 中学生・保護者③ 一般全分類
名字（カナ/漢字）または受付番号下5桁

画面上部のボタンが「今、どの名簿を検索するか」を決めます。検索欄はその下に1つだけあります。

「✓ この端末に保存済み」 が出ていれば、現在の受付記録はこの端末に保存されています。

「同期OFF / ●同期中 / ●オフライン」 は、ほかの受付PCとの共有状態です。

分類の使い方

大分類通常の使い方追加ボタン
① 在校生保護者生徒の名字で検索全学年 / 1年 / 2年 / 3年
② 中学生・保護者申込者の名字で検索9/5 / 9/6
③ 一般申込者の名字で検索9/5 / 9/6
全分類混雑時に全来校者を同時検索日付のみ

3列で分けている通常時は、各PCを担当分類に固定しておくと速いです。列が崩れたら、担当者は上の分類ボタンをその場で押し替えます。

分類ボタンを押しても受付記録は消えません。検索対象だけが変わります。

検索方法

名字で探す

ひらがな・カタカナ・漢字を使えます。例：さとう、サトウ、佐藤。

珍しい名字で読み方が複数ある場合は、候補の読みを複数登録してあります。画面には「カナザワ / カネザワ」のように候補を並べます。

受付番号で探す

②中学生・保護者、③一般は、受付番号全文でも下5桁だけでも検索できます。

例
受付番号 RQ00020220
→ 20220 でも ２０２２０ でも同じ人が見つかります。

全角数字と半角数字は自動で同じ数字として扱います。

中学生・保護者／一般の確認手順

名字を聞く
→
候補を出す
→
フルネーム確認

特に中学生名簿では、1つの氏名欄に家族・同行者・学校名などが一緒に記録されている場合があります。

その欄をこちらから読み上げないでください。
まず名字で候補を絞り、画面の候補を見ながら「フルネームをお願いします」と本人に言ってもらって一致を確認します。

一致したら 「この方で受付」 を押します。すでに別受付で処理されていれば 「受付済」 と時刻・端末名が表示されます。

在校生保護者の確認

在校生保護者は、生徒名簿のフリガナを使います。受付では保護者の名字を入力し、候補に表示された生徒の氏名・学年・組・番号で確認します。

  1. 「① 在校生保護者」を押す。
  2. 1年・2年・3年の担当列なら、学年ボタンも押す。
  3. 名字を入力する。
  4. 生徒名を確認する。
  5. 「この方で受付」 を押す。
学年が分からない、列を混ぜて受ける場合は 「全学年」 を選べます。

3台のPCで同時に使う

同じWi-Fiにつながっている必要はありません。学校Wi-Fi、別のWi-Fi、スマホのテザリングなど、各PCがそれぞれインターネットへ接続できれば共有できます。

  1. 3台すべてに同じ 目高祭受付名簿.xlsx を読み込む。
  2. ⚙を押す。
  3. 1台目で 「新しく作る」 を押して同期コードを作る。
  4. 3台とも同じ同期コードを入力する。
  5. 端末名は「受付A」「受付B」「受付C」のように別々にする。
  6. 「同期を開始」 を押す。
同期サーバーへ送るのは匿名ID・受付/取消・時刻・端末名です。名簿の氏名・フリガナ・学校名は送りません。

通信が切れたら

画面に 「⚠ 他の受付端末とは現在同期されていません」 と出ます。

受付は止めなくて大丈夫です。 そのPCの中に受付記録を保存し続けます。通信が戻ると未同期分を自動送信します。

注意： オフライン中は、別PCで今まさに受付した人を知ることができません。この時間だけは二重受付の可能性があります。完全に通信できない場合は、できるだけ①②③の列分けを維持してください。

データについて

この端末に保存するもの

  • 読み込んだ受付名簿
  • 誰を受付したか
  • 受付時刻
  • 名簿外として追加した人
  • 分類・日付・同期設定

ブラウザの保存領域（IndexedDB / localStorage）を使います。つまり、まずはこのPCの中に保存します。

受付終了時

⚙ → 「来校記録CSVを書き出す」 で記録を保存してください。さらに 「バックアップJSON」 も保存すると安全です。

共有PCの場合： 受付終了・バックアップ確認後、必要に応じて 「この端末から名簿＋受付データを完全削除」 を実行してください。

間違えたとき

違う人を受付した

その人をもう一度検索し、カードの 「受付を取り消す」 を押します。

分類を間違えた

分類ボタンを正しいものへ押し替えるだけです。すでに受付した記録は消えません。

日付を間違えた

9/5と9/6は別の受付記録です。正しい日付へ切り替えて受付し直し、誤った日の記録は検索して取り消してください。

困ったとき

名前を入れても出ない

①分類と日付を確認 → ②「全分類」で探す → ③カナ/漢字を変える → ④受付番号下5桁を試す、の順で確認します。

それでも見つからない

「＋ 名簿外の方を受付」 を使います。フリガナだけ必須です。

画面を閉じてしまった

同じPC・同じブラウザで開き、「前回の受付を続ける」 を押します。

「オフライン」と出る

受付は継続できます。Wi-Fiやテザリングが戻れば自動同期します。

スマホで使う方法

スマホでも表示できますが、本番受付ではExcelの選択・キーボード入力・複数人操作を考えるとPCまたはタブレットを推奨します。

iPhoneではSafariで公開URLを開き、共有メニュー → 「ホーム画面に追加」 でアプリのように起動できます。PWAの基本画面とこのマニュアルはオフライン対象です。

全分類3分類をまとめて検索するモード。混雑時に使います。
下5桁受付番号の最後の数字5文字。全角・半角どちらでも検索できます。
